# Security Policy

## Supported Versions

Only the latest release of `throttler` published on PyPI receives security fixes. If you are on an older version, please upgrade to the latest release first and check whether the issue is still present.

## Reporting a Vulnerability

If you find a security vulnerability in `throttler`, please report it privately instead of opening a public issue.

- Email: github@rmbk.me
- Subject: `[throttler] Security report: <short description>`
- Include: the affected version, steps to reproduce, and the impact as you understand it. A minimal reproduction is very helpful.

You will receive an acknowledgement, and the issue will be fixed in a new release. Please do not disclose the vulnerability publicly until a fixed version is released.

There is no bug bounty program for this project.
